# Problem Statement
Develop a robust, object-oriented Java console application for managing railway reservations, avoiding external frameworks and databases, and relying entirely on standard Java file I/O for data persistence. 

# Scope
The system will manage Passengers, Trains, and Tickets. It will provide functionalities for adding/updating passengers, checking train availability, booking/cancelling tickets, and generating basic reports.

# Target Users
- Passengers who need to book or cancel tickets.
- Administrators managing train data and analyzing reports.

# High-Level Features
- Command-line driven interactive menu.
- Simulated payment processing.
- Persistent storage using CSV files.
- Automated unique PNR generation.
- Seat availability management.

# Project Objectives
- Demonstrate solid grasp of Core Java (OOP, exceptions, collections, IO).
- Ensure a crash-resistant user interface using input validation.
- Maintain a clean layered architecture (CLI -> Service -> Repository -> Data).
